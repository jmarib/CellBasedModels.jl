# Bachelor's thesis: Bacterial chemotactic strategies for intestinal crypt colonization

This repository contains the code used to perform the simulations on bacterial chemotaxis in crypt-like strctures and how it affects their colonization. It contains:
 
- jmari_code: Code for the main simulations and analysis that were performed, including the simulations with a fixed attractant source, simulations for self-chemotactic agents, both with repellant and attractant, and with crypt-like geometry, for the crypt attractant and self-attractant scenario. This last can be modified to generate the five scenarios mentioned in the theis, by removing all chemotaxis, or the crypt attractant or self-chemotaxis, or changing the attractant self-chemotaxis to a repellent. 

- jmari_extended_code: This contains notebooks for the different tests performed both during the previous internhip and during the development of the thesis. This includes code for many possible combinations, as well as analysis performed.
